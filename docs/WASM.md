# TITAN WebAssembly Backend

`titan wasm <project>` emits a real WebAssembly module with exported `main` and named functions. The first backend block directly lowers integer/bool/nil constants, locals, arithmetic, signed division/remainder, bitwise operations, comparisons, calls and returns to Wasm instructions. Generated bytes are validated in tests with `wasmparser`.

Unsupported VM-managed values/control flow are rejected explicitly with function/opcode diagnostics rather than silently miscompiled. Structured control-flow lowering, strings/linear memory, browser imports, DOM bindings and source maps are subsequent Phase 6 blocks.
