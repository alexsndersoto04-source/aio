Titan — lenguaje de programación

Un lenguaje compilado y con tipos comprobados antes de ejecutar. Genera ejecutables nativos para Linux (x86-64 y ARM64, incluido Termux) y módulos WebAssembly. Trae una biblioteca estándar amplia: texto, red, bases de datos, criptografía, audio, imágenes, inteligencia artificial local y más.

El lenguaje

Sintaxis con llaves, tipos comprobados al compilar y los elementos habituales de un lenguaje moderno. Los ejemplos de esta página se ejecutaron con el compilador; la salida que se muestra es la real.

enums, match y manejo de errores
enum Forma {
    Circulo(float),
    Cuadrado(float),
    Vacio,
}

fn area(f: Forma) -> float {
    match f {
        Forma::Circulo(r) => 3.14159 * r * r,
        Forma::Cuadrado(l) => l * l,
        Forma::Vacio => 0.0,
    }
}

fn dividir(a: int, b: int) -> Result {
    if b == 0 {
        return Result::Err("división por cero")
    }
    Result::Ok(a / b)
}

fn main() {
    let formas = [Forma::Circulo(2.0), Forma::Cuadrado(3.0), Forma::Vacio]
    let areas = formas.map(|f| area(f))
    print("áreas: {areas}")
    match dividir(10, 0) {
        Result::Ok(v) => print("resultado {v}"),
        Result::Err(e) => print("error: {e}"),
    }
}
Salida
áreas: [12.56636, 9, 0]
error: división por cero

Qué incluye

  • Tipos int, float, bool, char, string, bytes, arrays, tuplas y mapas.
  • Funciones tipadas, parámetros por defecto, recursión y closures con captura de variables.
  • struct, enum con datos, impl, trait con métodos por defecto y alias de tipos.
  • match, if, while, loop y for sobre rangos y arrays.
  • Option, Result, el operador ? y std::try::catch.
  • Módulos, import entre archivos y proyectos con Titan.toml.
  • Interpolación de strings: "total = {total}".
  • map, filter, fold, find, any, all y sort_by sobre arrays.

Concurrencia

Tareas con spawn y join, canales con capacidad, select y esperas con tiempo límite. Las tareas son fibras cooperativas del runtime, no hilos del sistema: avanzan cuando una se bloquea o cede, y el runtime avisa si todas quedan bloqueadas para siempre (deadlock).

spawn, canales y join
fn productor(tx: Sender, n: int) -> int {
    let mut i = 1
    while i <= n {
        send(tx, i * i)
        i += 1
    }
    n
}

fn main() {
    let (tx, rx) = channel(2)
    let tarea = spawn || { productor(tx, 5) }
    let mut suma = 0
    let mut k = 0
    while k < 5 {
        suma += recv(rx)
        k += 1
    }
    print("suma de cuadrados = {suma}")
    print("la tarea envió {join(tarea)} valores")
}
Salida
suma de cuadrados = 55
la tarea envió 5 valores

Comprobaciones al compilar

El comprobador de tipos rechaza variables inexistentes, tipos incompatibles, llamadas con el número de argumentos equivocado, match no exhaustivos y asignaciones a variables no mutables. No hay conversión implícita de int a float.

Los errores de ejecución (desbordamiento de enteros, división por cero, índice fuera de rango) terminan el programa con un mensaje claro.

Servidor HTTP

Este programa se ejecutó y respondió a dos peticiones curl reales.

servidor mínimo
fn main() {
    let servidor = std::server::start("127.0.0.1:8099")
    print("escuchando en {std::server::local_addr(servidor)}")
    let mut atendidas = 0
    while atendidas < 2 {
        let peticion = std::server::accept(servidor, 30000)
        if peticion >= 0 {
            let ruta = std::server::path(peticion)
            std::server::respond(peticion, 200, "hola desde Titan, ruta {ruta}")
            atendidas += 1
        }
    }
    std::server::stop(servidor)
}

Instalación

Titan se instala construyéndolo desde las fuentes; solo hacen falta bash y gzip. Los paquetes ya compilados para Linux x86-64 y ARM64 se publican en la página de Releases a partir de la versión 1.1; las versiones 1.0.x de esa página son del prototipo antiguo en Rust.

Linux x86-64
git clone https://github.com/alexsndersoto04-source/aio.git
cd aio
bash selfhost/bootstrap.sh      # tarda 2-3 minutos
selfhost/titan version

El repositorio incluye una semilla: una copia ya compilada del compilador (7,7 MB, selfhost/semilla/). bootstrap.sh la usa para compilar el compilador escrito en Titan, y este se compila a sí mismo dos veces más; el script comprueba que las tres versiones sean idénticas byte a byte. Después construye la herramienta titan.

El ejecutable busca su runtime en la carpeta native/ que está a su lado. Para usarlo desde cualquier carpeta basta un enlace simbólico:

enlace en el PATH
ln -s "$PWD/selfhost/titan" ~/.local/bin/titan

Termux (Android, ARM64)

El paquete titan-v1.0.0-linux-aarch64.tar.gz lo fabrica el flujo «Linux ARM64 (Termux)» de GitHub Actions. El instalador selfhost/instalar-termux.sh instala clang (en ARM64 Titan lo usa para producir el ejecutable final) y deja titan en el PATH. Ver la guía de Termux, que explica también qué no se ha probado todavía.

Plataformas

Titan genera ejecutables nativos estáticos para Linux. El runtime llama directamente al núcleo de Linux, sin biblioteca C.

WebAssemblyDisponibletitan wasm genera el módulo; DOM, eventos, fetch, Canvas 2D y WebGL2 funcionan con un host JavaScript.

Con LLVM se puede compilar desde x86-64 para ARM64: titan compile programa.titan --target aarch64.

Los binarios de la release v1.0.0 pertenecen a la versión antigua, escrita en Rust, y no se actualizan. La versión actual se construye desde las fuentes; los paquetes nuevos se publican en Releases a partir de la versión 1.1.

Cómo funciona

Todas las etapas están escritas en Titan.

1Lexer y parser: convierten el texto en un árbol sintáctico.
2Comprobador de tipos: valida el programa antes de generar nada.
3Generador de bytecode y optimizador: representación intermedia con cálculo de constantes, eliminación de código muerto y entrega de valores sin copia en la última lectura.
4Generador de código: x86-64 propio (ELF directo), LLVM (x86-64 y ARM64) o WebAssembly.
5Runtime y biblioteca estándar, también en Titan, que se compilan junto con el programa. El resultado es un ejecutable sin máquina virtual.

El compilador se compila a sí mismo: la versión 1 (hecha con la semilla), la 2 (hecha con la 1) y la 3 (hecha con la 2) son idénticas byte a byte. Detalle en la arquitectura.

Límites conocidos

Lo que Titan todavía no hace o no se ha comprobado.

  • Plataformas: sin ejecutable para macOS ni Windows. En ARM64 no se ha probado en un teléfono real.
  • Permisos: los ejecutables nativos no tienen sandbox ni sistema de permisos; un programa puede leer archivos, lanzar procesos y usar la red.
  • Lenguaje: no hay genéricos definidos por el usuario, ni referencias (&T), ni break con valor; algunos patrones de match (alternativas con |, destructuring anidado) se rechazan con un error claro.
  • Memoria y tareas: las tareas son fibras cooperativas (no usan varios núcleos) y no se puede limitar la memoria por tarea.
  • Audio: decodifica WAV, FLAC y Ogg Vorbis; no MP3, Opus, AAC, AIFF ni CAF. La salida a altavoces usa un reproductor del sistema y no se ha probado con hardware real.
  • SQLite: sin FTS, RTREE, ATTACH, EXPLAIN, tablas temporales ni WITHOUT ROWID; VACUUM y ANALYZE no hacen nada.
  • IA: el motor ONNX y BERT están pensados para modelos pequeños (entrada y modelo hasta 64 MiB).
  • Web: std::web y std::wasm solo funcionan con un host JavaScript.
  • ARM64: el depurador y el motor de audio no se han probado en ARM64; compilar en el dispositivo requiere clang y lld.

La lista completa, con el detalle de cada pieza, está en selfhost/ESTADO.md.

Origen

Titan empezó como un prototipo escrito en Rust. El compilador, el runtime y la biblioteca estándar se reescribieron en Titan y el código Rust se eliminó del repositorio; la última versión con Rust sigue disponible en el historial de git (etiqueta ultimo-con-rust). El nombre «Zett» aparece en algunos archivos y mensajes porque así se distribuyó antes, sobre todo en Termux.
