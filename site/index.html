EL LENGUAJE

Una base clara para programas reales.

Titan combina una sintaxis expresiva con comprobaciones explícitas y un formato portable, para que los errores se encuentren antes de ejecutar.

01

Tipos que ayudan

Funciones, closures, structs, enums, métodos, traits, aliases y módulos con imports. Option y Result hacen visibles los casos que pueden fallar.

structenumResult
02

Bytecode comprobado

Los artefactos .tbc llevan versión y checksum; se validan antes de ejecutarse, incluidos saltos, aridad, locales y llamadas nativas.

.tbcCRC-32source maps
03

Un lenguaje, más destinos

El compilador genera bytecode para la VM y cuenta con backends LLVM y WebAssembly para destinos adicionales.

VMLLVM IRWASM

RUNTIME Y SEGURIDAD

Control explícito, desde el bytecode hasta los efectos.

La VM valida el programa antes de ejecutarlo y puede restringir operaciones del sistema mediante capacidades.

Conoce la arquitectura→
01

Validación antes de ejecutar

Formato, checksum, tamaños, funciones, instrucciones, saltos y llamadas se comprueban antes de aceptar un .tbc.

02

Sandbox por capacidades

--sandbox deniega filesystem, procesos, red y environment, sin desactivar funciones puras.

03

Concurrencia con límites claros

Tareas sobre threads del host, canales acotados, cancelación cooperativa y cuotas de memoria por tarea.

EMPIEZA CON TITAN

Instala Zett y ejecuta tu primer programa.

Elige el paquete de tu plataforma en los releases oficiales. También puedes instalar Zett desde Termux.

Todos los releases
Inicio rápido · Linux x86-64
curl -L https://github.com/alexsndersoto04-source/aio/releases/latest/download/zett-linux-x86_64.tar.gz | tar xz
cat > hi.titan <<'EOF'
fn main() {
    print("Hola, Titan")
}
EOF
./zett run hi.titan
Linux x86-64 Linux ARM64 Linux ARMv7 macOS Apple Silicon Windows x86-64

El binario Linux necesita la biblioteca ALSA real (libasound.so.2). Instálala desde los paquetes de tu distribución si falta.

ANDROID · TERMUX

Instalación en Termux

Añade el repositorio oficial y usa el gestor de paquetes de Termux.

echo 'deb [trusted=yes] https://raw.githubusercontent.com/alexsndersoto04-source/aio/zett-repo ./' > "$PREFIX/etc/apt/sources.list.d/zett.list"
pkg update
pkg install zett
Guía de Termux →

El origen APT usa trusted=yes, por lo que APT no verifica una firma del repositorio. Revisa la guía y el canal de distribución antes de instalar.

EN DESARROLLO

TRANSPARENCIA DEL PROYECTO

El self-hosting sigue avanzando.

El compilador y la VM de referencia actuales están implementados en Rust. El bootstrap nativo de Titan pasa la recompilación en tres generaciones; portar la biblioteca estándar y el runtime sigue en curso. El inventario estático registra fuente Titan para 521 de 816 firmas nativas, pero ese recuento no equivale a paridad de comportamiento.
