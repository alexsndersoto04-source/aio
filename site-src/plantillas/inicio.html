Titan — lenguaje de programación

Tipos comprobados antes de ejecutar y ejecutables nativos para Linux (x86-64 y ARM64, incluido Termux), además de módulos WebAssembly. Incluye una biblioteca estándar amplia: texto, red, bases de datos, criptografía, audio, imágenes e inteligencia artificial local.

Características

Lo esencial de Titan

Tipado estático y genéricos

El comprobador de tipos valida funciones, structs, enums y genéricos <T>, rechaza tipos incompatibles y exige match exhaustivos antes de generar código.

Ejecutables nativos

Genera código de máquina: x86-64 con generador propio, o x86-64 y ARM64 mediante LLVM. Sin máquina virtual al ejecutar.

Tareas y canales

spawn, join, canales con capacidad, select y tiempos límite sobre fibras cooperativas, con detección de bloqueo total.

WebAssembly

titan wasm genera módulos con memoria lineal, strings, arrays, mapas y structs, más un host JavaScript para DOM, fetch y Canvas.

Biblioteca estándar

812 funciones escritas en Titan, sin dependencias externas: datos, red, criptografía, bases de datos, multimedia e IA local.

Herramientas integradas

Una CLI, titan, para proyectos, pruebas, REPL, depurador y servidores LSP y DAP; y Zett, el gestor de paquetes con firmas Ed25519.

Plataformas

Ejecutables nativos para Linux

Los programas son ejecutables estáticos: el runtime llama directamente al núcleo de Linux, sin biblioteca C. Hay paquetes precompilados para x86-64, ARM64 y ARM de 32 bits, y cada binario tiene su paquete oficial zett con el gestor del sistema (apt en Debian/Ubuntu, pkg en Termux).

Probada · x86_64

Linux x86-64

Compilador nativo, herramienta titan, gestor de paquetes zett y programas generados sin dependencias externas. Punto fijo del compilador verificado.

Probada · aarch64

Linux ARM64 · Termux

Paquete nativo de 64 bits (aarch64) para servidores ARM64 y Android (Termux). Compila y ejecuta programas mediante LLVM (requiere clang y lld); 95 programas verificados con salida idéntica a x86-64.

Comprobada con emulador · armv7

Linux ARM de 32 bits

Compilador para ARM de 32 bits (armv7), pensado para Android/Termux de 32 bits y equipos ARMv7. Compila con LLVM (requiere clang y lld). El binario del paquete se comprobó bajo el emulador de ARM32: arranca y compila un programa de verdad; en un aparato de 32 bits no se ha probado todavía.

Disponible

WebAssembly

titan wasm genera el módulo; DOM, eventos, fetch, Canvas 2D y WebGL2 funcionan con un host JavaScript.

Previsto

macOS y Windows

Sin ejecutable por ahora: falta portar el runtime, que usa llamadas directas de Linux.

Desde x86-64 también se puede hacer compilación cruzada para ARM64 con LLVM: titan compile programa.titan --target aarch64.

Descargas oficiales

Paquetes oficiales zett y precompilados para Linux

Cada binario del compilador (x86-64, ARM64 y ARM de 32 bits) tiene su paquete .deb con el nombre zett, que se instala con el gestor del sistema —apt en Debian/Ubuntu y pkg en Termux— y deja titan y zett en el PATH. También están los .tar.gz de siempre, que no necesitan instalación: dentro va el ejecutable titan, el enlace zett y la carpeta native/.

Instalación desde código fuente

Construir Titan desde las fuentes

Si estás en Linux x86-64 y prefieres construir el compilador completo desde cero, solo necesitas bash y gzip. El proceso verifica automáticamente la autocompilación en tres etapas.

1

Construir

Tarda unos 2–3 minutos.

{{COD:Linux x86-64|git clone https://github.com/alexsndersoto04-source/aio.git\ncd aio\nbash selfhost/bootstrap.sh\nselfhost/titan version}}
2

Dejarlo en el PATH

El ejecutable busca su runtime en la carpeta native/ que está a su lado.

{{COD:enlace simbólico|ln -s "$PWD/selfhost/titan" ~/.local/bin/titan}}
3

Crear un proyecto

Genera Titan.toml y src/main.titan.

{{COD:terminal|titan new mi_app\ncd mi_app\ntitan run}}
Cómo se construye. El repositorio incluye una semilla: una copia ya compilada del compilador (7,7 MB, selfhost/semilla/). bootstrap.sh la usa para compilar el compilador escrito en Titan, que luego se compila a sí mismo dos veces; el script comprueba que las tres versiones sean idénticas byte a byte.
Paquetes para Linux x86-64, ARM64 y ARM de 32 bits. En cada lanzamiento, GitHub Actions construye y verifica automáticamente los .tar.gz de las tres arquitecturas y los seis .deb (sistema y Termux) con sus repositorios apt, junto con las sumas SHA-256. El paquete de x86-64 se prueba en la propia CI, el de ARM64 en una máquina ARM64 real y el de ARM de 32 bits con el emulador. En Termux, el script selfhost/instalar-termux.sh descarga la última versión, instala clang y configura titan y zett en el PATH.

Estado del proyecto

Qué está verificado y qué no

Verificado

  • Punto fijo: el compilador se compila a sí mismo; las etapas 1, 2 y 3 son idénticas byte a byte.
  • Genéricos <T>: funciones, structs, enums, alias e impl<T> con inferencia de tipos y sintaxis turbofish ::<T>.
  • Biblioteca estándar: 812 de 812 funciones con cuerpo en Titan.
  • ARM64 real: 95 programas con salida idéntica a x86-64, en un servidor ARM64 de GitHub Actions.
  • Depurador y DAP: 40 y 20 casos de prueba en x86-64.
  • Integración continua: pruebas en GitHub Actions en cada cambio.

Límites conocidos

  • Plataformas: sin ejecutable para macOS ni Windows, ni para ARM de 32 bits; ARM64 probado en servidor ARM64 y arranque en Termux.
  • Permisos: los ejecutables nativos no tienen sandbox; un programa puede leer archivos, lanzar procesos y usar la red.
  • Lenguaje: sin referencias prestadas (borrowing) ni break con valor.
  • Tareas: fibras cooperativas, sin paralelismo entre núcleos; no se puede limitar la memoria por tarea.
  • Audio: WAV, FLAC y Ogg Vorbis; sin MP3, Opus ni AAC. La salida a altavoces no se ha probado con hardware real.
  • SQLite: sin FTS, RTREE, ATTACH ni tablas temporales.
  • IA: ONNX y BERT para modelos pequeños (hasta 64 MiB).
